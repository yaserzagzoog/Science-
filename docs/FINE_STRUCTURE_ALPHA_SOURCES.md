### How to add these to NotebookLM (notebook: **Fine Structure α**)

1. Open the notebook → **+ إضافة مصدر** (Add source)
2. Choose **موقع إلكتروني / Website**
3. Paste one URL and confirm; repeat for each
   (NotebookLM also lets you paste several URLs at once in the website box — one per line)
4. Free tier caps at 50 sources per notebook — this pack is 40, so it fits.

Tip: for arXiv, the `/abs/` page imports cleanly; if you want the full paper text
instead, swap `/abs/` for `/pdf/` in the URL and NotebookLM will ingest the PDF.
